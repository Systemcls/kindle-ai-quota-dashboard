# Kindle 兼容性

## 网页布局

网页采用基础 HTML 表格保持两列，不依赖 CSS Grid 或 Flexbox；窄屏也保留日期 / 天气、Codex / GLM 的并排关系，DeepSeek 占下一整行。颜色提供普通 CSS 值作为回退，供不支持 CSS 变量的旧浏览器使用。

此网页兼容处理不代表下方越狱启动器支持咪咕版。咪咕版的实际显示仍需在设备浏览器中确认。更新后若设备保留旧布局，可重新打开带 `?v=20260909-table1` 的页面地址以避开旧首页缓存。

## 已验证范围

首个开源候选版本只声明支持我们实际验证过的 KPM 平台：

- `kindlehf`
- `kindlepw2`

它依赖越狱环境中的 KPM、`kindle_browser`、`lipc-*`、`eips` 和 Kindle GUI 服务。设备代号相同也不代表所有固件行为完全一致。

## 风险

启动器会暂时停止 Kindle 原生 GUI、禁止屏保并启动内置浏览器。退出脚本负责恢复 GUI。固件升级可能改变服务名、浏览器路径或电源键事件格式。

首次测试前：

1. 保留 SSH 或 KTerm 恢复手段。
2. 确认能够执行退出脚本。
3. 不要在未列入兼容表的设备上直接长期运行。
4. 先用 KPM 卸载流程验证可恢复，再把它作为常驻面板。
